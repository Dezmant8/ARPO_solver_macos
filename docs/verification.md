Все ответы имели usage; суммы взяты из MLX, без оценки по символам.
Обе реализации прошли строгую сборку C89 и отдельный клиент через Eco bus с UBSan:
signed minima, signed zero, null me/out, QueryInterface и баланс ссылок.
Десять double-входов от ±1e-200 до ±1e200 совпали с fabs, ошибка 0 в проверенных случаях.
NaN и бесконечности не входят в область проверки.

Это одна техническая пара. Подробному варианту явно продлили лимит запросов с 12 до 16;
все его прежние расходы сохранены. Конечные лимиты различаются, поэтому результат
не доказывает изолированное влияние длины промпта. Предварительные отладочные серии
с другими контрактами/протоколами сохранены отдельно и не смешаны с этой парой.
Для учебного исследования выполняйте несколько пар и описывайте ручные уточнения.
