# Темы лабораторных

Краткое изложение тем из предоставленного списка; это справочник организатору эксперимента.
Локальная модель получает только два промпта выбранной темы и общий проект с интерфейсом.
Список не заменяет актуальное задание преподавателя. Код старого Eco требует адаптации к выбранному SDK.

Общие требования: новый ACOM компонент, C89, соответствующие числовые типы; собственный алгоритм
без libc/сторонних библиотек в компоненте; консольный клиент и независимые проверки; отчёт Word
с описанием, точностью относительно C/MATLAB и сравнением промптов. Несколько выбранных алгоритмов
оформляются отдельными компонентами с выбором в клиенте. Для сложных тем нужны замеры алгоритма.
Точный контракт, входной диапазон и N знаков задаются до генерации. Числовые типы Eco берутся из SDK.

## Дополнительная архитектура

Для генераторов, сортировок/поиска, сигналов/матриц и ИИ может быть выбран расширенный вариант:
сервис без состояния и объект с собственными данными, оба показаны клиентом; сравниваются удобство
и память. Это дополнительный объём, который не включается автоматически в каждую лабораторную.
История оптимизации промптов и характерные ошибки модели отражаются в отдельном разделе отчёта.
